# 输入

接口输入参数格式：

```typescript
{
  imageUrl："图片url",
  labelType: "标注类型", //0：图像分类、1：物体检测、2：图像分割
  subLabelType: "标注工具", // 0：矩形框、1：直线、2：圆框
  tags: [
    {
      tagId："标签ID",
      tagName："标签名称",
      color："标签颜色"
    }
  ]
}
```

# 输出

### 检测任务

检测任务接口返回数据格式：

```typescript
{
  code: "状态", //0：成功、1：异常
  message: "提示信息",
  data: RectOption[] | LineOption[] | CircleOption[] //不同subLabelType，返回不同数据结构的对象数组
}
```

```typescript
// subLabelType=0，矩形：
interface RectOption {
	bbox: {
		xmin: number;
		ymin: number;
		xmax: number;
		ymax: number;
	};
	bbox_label: number; // 保存tagId
	truncated: number;
	area: number;
	remark?: string; // 备注信息
}
// subLabelType=1，直线：
interface LineOption {
	line: {
		xmin: number;
		ymin: number;
		xmax: number;
		ymax: number;
	};
	line_label: number;
	length: number;
	remark?: string;
}
// subLabelType=2，圆框：
interface CircleOption {
	coor: {
		x: number;
		y: number;
	};
	circle_label: number;
	radius: number;
	truncated: number;
	area: number;
	remark?: string;
}
```

### 分类任务

分类任务接口返回数据格式：

```typescript
{
  code: "状态", //0：成功、1：异常
  message: "提示信息",
  data: [
    {
      tagId："标签ID",
      tagName："标签名称",
      color："标签颜色"
    }
  ] //返回标签信息
}
```
